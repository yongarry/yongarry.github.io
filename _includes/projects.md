<h4 style="margin:0 10px 0;">Spectral Normalization for Lipschitz-Constrained Policies <span style="float:right; font-weight:normal; font-style:italic;">2025&ndash;Present</span></h4>

<ul style="margin:0 0 20px;">
  <li>Proposed Spectral Normalization (SN) as a memory-efficient alternative to gradient-penalty-based Lipschitz-Constrained Policies (LCP), suppressing high-frequency torque fluctuations from unrealistic simulation assumptions while achieving comparable performance with significantly reduced GPU memory overhead.</li>
  <li>Preprint on <a href="https://arxiv.org/abs/2504.08246"><autocolor>arXiv</autocolor></a> &mdash; target venue: ICRA after follow-up study.</li>
  <li>Experimental video: <a href="https://youtu.be/Kr26Y5CayyU"><autocolor>link</autocolor></a></li>
</ul>
